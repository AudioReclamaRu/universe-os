# UNIVERSE OS 2.0 — в браузере

Интерактивная модель **ТОРВ / ТабАк** (`UNIVERSE 2.0`): граф Кэли 4D→3D, матрица
квантования масс, фазовый монитор Ψ, узловой стресс, энергия вакуума и панель констант.

Открывается по ссылке в любом браузере — ничего устанавливать не нужно:

**https://audioreclamaru.github.io/universe-os/**

## Как это работает

Страница поднимает [Pyodide](https://pyodide.org) (CPython + numpy + matplotlib,
скомпилированные в WebAssembly) и запускает `app.py` — это исходный
`UNIVERSE_2.0.py` плюс веб-обвязка. Никакого сервера нет: всё считается
в браузере посетителя.

* `index.html` — загрузчик, экран загрузки, масштабирование под окно.
* `app.py` — модель. Верхняя часть — исходный `UNIVERSE_2.0.py` без изменений;
  ниже блок «WEB BUILD» с классом `UniverseWeb`, который:
  * создаёт артисты один раз и обновляет их на месте (`set_data`/`set_offsets`/`set_text`)
    вместо пересоздания ~400 объектов каждый кадр — иначе браузер выдавал бы ~0.8 кадра/с;
  * рисует фигуру в 72 dpi (1440×810) и масштабирует под экран;
  * заменяет эмодзи режимов на ASCII-маркеры (в шрифтах DejaVu эмодзи нет).

## Что можно нажимать

* **Speed** — скорость эволюции Ψ.
* **Ψ threshold** — порог топологического коллапса.
* **RESET** — перезапуск вселенной.
* **PAUSE / RESUME** — пауза.

Клики по слайдерам и кнопкам пересчитываются по реальному размеру холста
(в Pyodide-webagg `ratio` остаётся равным 1, хотя холст растянут CSS-трансформацией —
без этой поправки клики попадали мимо виджетов).

## Производительность

Модель тяжёлая: фигура из шести панелей, 448 рёбер графа и 128 узлов перерисовывается
целиком. В браузере это ~1.5–2 кадра/с, в нативном Python — ~3–4 кадра/с.
Поэтому вращение решётки выглядит медленным и плавным, а не быстрым.

Первый запуск скачивает ~20 МБ (Pyodide + numpy + matplotlib) и стартует 10–30 с,
дальше браузер берёт всё из кеша.

## Локальный запуск

```powershell
# из папки с index.html
python -m http.server 8811
# открыть http://127.0.0.1:8811/
```

Открывать `index.html` двойным щелчком (`file://`) нельзя — браузер не даст
загрузить `app.py` из файловой системы.

## Пересборка app.py

`app.py` собирается из исходника `UNIVERSE_2.0.py` и патча `web_patch.py`:

```powershell
python build.py
```

Оригинальный `UNIVERSE_2.0.py` при этом не изменяется.
