# GIZA PRIME — Phase B CI portability contract

Цель: разделить проверку математики и данных Фазы B от доступности персонального
архива исходников. Красный CI на `3c280d0` был вызван не ошибкой геометрии, а тем,
что тестовые классы собирали реальный каталог из захардкоженных путей `E:\...`,
которых нет на GitHub runner.

## Два контура

### 1. Portable CI — обязателен везде

Файл: `test_phase_b_portable.py`. Не читает исходные директории и не зависит от ОС.

Покрывает:

* все семь адаптеров на компактных детерминированных фикстурах;
* геометрические примитивы, контракт model record и отказ от построения surface;
* CRS: 5 раздельных систем, 0 трансформаций, datum не повышается;
* identity: кандидаты не подтверждаются, 0 потерянных наблюдений;
* relations: 154 контрактных записи, 0 cross-campaign геометрических связей, 0 физических механизмов;
* idealization: 24 модели, `IDEALIZED_MODEL`, withheld Petrie, `null`-поверхности;
* ошибки данных: отсутствующее описание/координаты/northing, нефинитные числа;
* уже опубликованные канонические реестры и их доказательственные ограничения.

Алгоритмические тесты в `test_phase_b.py` (CRS, identity, relations, idealization)
тоже переведены на чтение опубликованного `phase_b_observations.json` — они
проверяют математику на зафиксированных данных, а не доступность диска.

### 2. Full-source integration — только при смонтированных исходниках

Файл: `test_phase_b.py`, классы `CatalogTests`, `ObservationTests`,
`DeterminismTests`, `IntegrationParityTests`.

Проверяет два настоящих каталога: 15 raw и 8 derived файлов, SHA-256,
KMZ ↔ JSON, все 12 078 записей, а также побайтовую парадность пересобранных
реестров с опубликованными.

Если источники не смонтированы, классы получают явный статус
`SKIPPED — SOURCE DATA NOT MOUNTED` с причиной (отсутствует raw/derived root или
список недостающих derived-файлов). Просто отключить эти тесты запрещено:
эквивалентные свойства проверены portable-контуром.

## Конфигурация

| Переменная | Назначение |
| --- | --- |
| `GIZA_PRIME_RAW_ROOT` | точный raw-каталог вместо значения по умолчанию |
| `GIZA_PRIME_DERIVED_ROOT` | точный derived-каталог вместо значения по умолчанию |
| `GIZA_PRIME_REQUIRE_FULL_SOURCE` | `1/true/yes/on` — отсутствие источников остаётся ошибкой |

Значения по умолчанию оставлены прежними (`E:\GIZA_PRIME_LAB\gizalab\...`), поэтому
пересборка без переменных окружения остаётся побайтово тождественной
опубликованным артефактам. Поиск по альтернативным путям не производится:
указанный каталог либо используется точно, либо диагностируется как отсутствующий.

## Команды

```powershell
$env:OPENBLAS_NUM_THREADS='1'
# Локально: оба контура
python -m unittest discover -v -p "test_*.py"

# Имитация GitHub без исходников: portable зелёный, integration SKIPPED
$env:GIZA_PRIME_RAW_ROOT='F:\Pill\tmp\opencode\missing_raw'
$env:GIZA_PRIME_DERIVED_ROOT='F:\Pill\tmp\opencode\missing_derived'
python -m unittest discover -v -p "test_*.py"

# Обязательная полная интеграция: отсутствие источников = ошибка
$env:GIZA_PRIME_REQUIRE_FULL_SOURCE='1'
python -m unittest discover -v -p "test_*.py"
```

## Что не делалось

* Ни один тест не удалён и не отключён без эквивалентной portable-проверки.
* Пользовательский архив не копируется в репозиторий.
* `phase_b_observations.json` и `phase_b_model_registry.json` не пересобирались:
  их публикация остаётся неизменной.
* Коммит/push после этого исправления не выполняются без отдельного GO владельца.
