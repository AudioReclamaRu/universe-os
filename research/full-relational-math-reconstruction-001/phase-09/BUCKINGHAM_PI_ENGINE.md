# Phase 09 — Buckingham–Π engine and dimensional relation space

## Purpose

Phase 08 generated ratios only between quantities with identical dimensions. Phase 09 generalizes this to arbitrary sets of physical variables: it constructs the exact dimension matrix, finds its rational null space and returns a basis of dimensionless monomial groups.

This is a core relation-discovery primitive. It identifies dimensional combinations a physical law may depend on; it does not choose the law or establish its mechanism.

## Files and use

- buckingham_pi.py — exact rational linear-algebra implementation; Python standard library only.
- test_buckingham_pi.py — unit tests.
- example_input.json — synthetic fluid-dynamics variable set.
- example_report.json — generated output.

Run:

    python -m unittest -v
    python buckingham_pi.py example_input.json --output example_report.json

## Mathematical construction

For variables q₁, …, qₙ, each with a dimension vector over the seven SI base dimensions, build the matrix D with D[a,i] equal to the exponent of base dimension a in variable qᵢ.

Find all exponent vectors v satisfying Dv = 0. Each vector defines a dimensionless monomial:

    Π = product(qᵢ ** vᵢ).

The exact implementation uses rational Gaussian elimination and reduced row-echelon form. It reports matrix rank, nullity n − rank(D), pivot and free variables, a canonical null-space basis, exact rational exponents, numeric Π values when every variable value is supplied and positive, and source/unit/evidence-status metadata.

The basis is not unique. Any invertible change of basis within the null space produces another equally valid set of dimensionless groups. The engine records complete alternative bases generated by elementary unimodular changes. These are examples, not an enumeration of all possible bases.

## Demonstration: Reynolds group

For density ρ, speed U, characteristic length L and dynamic viscosity μ:

- [ρ] = M L⁻³;
- [U] = L T⁻¹;
- [L] = L;
- [μ] = M L⁻¹ T⁻¹.

The dimension matrix has rank three and a one-dimensional null space. The engine recovers:

    Π = ρ U L / μ,

the Reynolds number. The numerical values in the example are synthetic and are used only to demonstrate evaluation after dimensional derivation.

## Demonstration: pendulum variables

For period T, length L, mass m and gravitational acceleration g, the engine returns:

    Π = T² g / L.

This is dimensionless and equivalent to the square of T sqrt(g/L). Dimensional analysis alone does not derive the pendulum equation.

## Constraints and interpretation

- Numeric evaluation requires positive finite values. Dimensional analysis itself requires dimensions only; values are optional.
- Values must use coherent units. The engine cannot repair mixed units or incorrect unit assignments.
- Results depend on the declared variable set. An omitted governing variable can change the derived groups.
- Buckingham–Π does not determine the number or form of functional relationships, coefficients, causality or boundary-condition dependence.
- Dimensionless does not mean universal, scale-invariant, fundamental or physically causal.
- The seven SI base dimensions are a unit-system basis, not a claim that all physical theories reduce to seven independent ontological ingredients.
- The algorithm returns one canonical basis plus selected equivalent alternatives. It does not search arbitrary nonlinear dimensionless functions, transcendental combinations or hidden variables.

Every generated group returns to the full Canonical Pattern Atlas and Phase 07 relation passport. Numeric Π values can be screened by Phase 08; structural comparisons require specialized comparators.

Eight tests passed locally. They verify exact Reynolds and pendulum groups, rank/nullity, multiple independent directions, completeness and linear independence of alternative bases, dimensionless inputs, invalid names/dimensions and paired binary/ternary integer keys.

The CLI example ran and its exact rational exponents and expected group value were checked. This is local module-level verification, not a full-repository CI claim.
