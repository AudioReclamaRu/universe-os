## 2. Область тестирования

Workflow выполняет:

    python -m unittest discover -s tests/giza_spatial -v

В набор входят:
- синтетические тесты двумерного преобразования координат;
- тесты приёма и валидации манифеста фоновых колебаний;
- проверки метаданных, трёх компонент, времени, путей, размеров файлов и SHA-256.

Точный фактический состав тестов определяется состоянием репозитория на commit, указанный выше. Успешное выполнение проверяет программную реализацию на тестовых данных, но не подтверждает геодезическую привязку, калибровку датчиков или физическую корректность интерпретации реальных измерений.

## 3. Граница вывода

Даже при успешном CI остаются отдельными этапами:
- получение реальных исходных временных рядов;
- проверка происхождения и калибровки;
- обработка и оценка спектральной неопределённости;
- сравнение с независимыми измерениями;
- валидация физической модели;
- историческая интерпретация.

CI не является экспериментом и не заменяет данные реального объекта.

## 4. Итоговая фиксация

Этот документ фиксирует фактический результат конкретного запуска GitHub Actions и конкретного commit. Последующие изменения кода требуют нового запуска и не наследуют автоматически статус этого запуска.
